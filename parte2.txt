AMPLIACIÓN PRÁCTICA SPOTIFY: Javascript + Json

Es hora de darle algo de dinamismo a nuestra web. Para ello ahora se pide que:

La información de las canciones no sea hardcodeada en el HTML como originalmente, sino que sean datos recogidos y leídos de un fichero JSON.
Crea un fichero Json que almacene información sobre canciones, guardando propiedades y valores para el nombre de la canción, nombre de artista/s, y src de imagen. Dale la estructura y valores que consideres más adecuado a este fichero.
Nada más abrirse la web, debe leerse este fichero JSON y recorrer sus datos para representarlos en el lugar correspondiente, sustituyendo así la información de canciones que hubiera previamente en el html.
Se debe permitir interacción con la web, de tal forma que si se pulsa en el botón de Iniciar Sesión, Crear una lista, o el botón de reproducción de cualquier canción se muestre una nueva ventana emergente de Login.
Esta ventana debe superponerse al contenido de la web, mostrando lo siguiente:
El logotipo de Spotify, seguido de un título (recuperado mediante JSON).
Un formulario de Login con un input para correo electrónico y un input para contraseña, ambas etiquetas recuperadas mediante JSON.
Un botón con el texto Continuar (recuperado mediante JSON). Al ser pulsado:
Comprueba si la combinación introducida de correo electrónico y contraseña coincide con alguna del listado que se debe encontrar en el JSON. Este JSON debe tener al menos 10 usuarios de entre los cuales haga la búsqueda. 
Si se deja algún campo en blanco, debe informar debajo de este en texto rojo.
Si la combinación de contraseña y correo no es válida (porque no encuentra ninguno en el listado de usuarios) debe mostrar un mensaje de error en rojo.
Si el login es exitoso, se cierra automáticamente esta ventana, y el botón que antes mostraba el texto “Iniciar Sesión” mostrará “cerrar sesión”.
Si se hace click en cualquier lugar fuera de esta ventana emergente antes de completar el login, se cierra.
